# Architecture

## Overview
AINetwork adopts a modular architecture with Spring Boot 3 backend, Vue 3 frontend and MySQL 8.4.

## Core Services
- API Gateway
- Auth/RBAC
- Device Service
- Alarm Service
- Topology Service
- AI Copilot Service
- Automation Service

## Infrastructure
- MySQL 8.4
- Redis
- Kafka
- Prometheus + Grafana
- Loki
- Docker Compose
- Kubernetes

## Design Principles
- API First
- AI First
- Event Driven
- Stateless services
- Horizontal scalability
